# Python Library Installation Guide
This repository uses a `libs.txt` file to manage and install Python dependencies.
Just create a venv or directly install in your python using the command *pip install -r libs.txt* using the cmd pathed to the main folder (*../MazePlayground*)


# Controls
## `Maze.py`
* **Right Click:** Place the finish point.
* **Spacebar:** Advance to the next algorithm (active once the current algorithm finishes).

## `GameOfLife.py`
* **Left Click:** Draw cells on the grid.
* **Spacebar:** Pause / Unpause the simulation.
